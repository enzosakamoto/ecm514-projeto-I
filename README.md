# Projeto I – Saneamento Básico e Desempenho no ENEM 2020

## Objetivo

Este projeto investiga a relação entre indicadores de saneamento básico (água tratada e esgoto) e o desempenho dos participantes do ENEM 2020, utilizando dados oficiais do Sistema Nacional de Informações sobre Saneamento (SNIS) e dos microdados do ENEM. O foco é analisar se a infraestrutura de saneamento influencia as oportunidades educacionais e os resultados dos estudantes brasileiros.

Este trabalho foi desenvolvido como parte da disciplina ECM514 ministrada pelo professor [Rogerio de Oliveira](https://github.com/Rogerio-mack).

## Dados Utilizados

- **SNIS (Sistema Nacional de Informações sobre Saneamento):** Indicadores municipais de água e esgoto para o ano de 2020.
- **ENEM 2020 (Microdados):** Informações detalhadas sobre desempenho, presença, e respostas ao questionário socioeconômico dos participantes.

## Como Executar

1. Baixe os dados do SNIS e ENEM 2020 ou utilize os links S3 já configurados no notebook.
2. Execute o notebook `IMT_Projeto_S1_enzo_joao_pedro_rafael_vitor.ipynb` na pasta `src/`.
3. Recomenda-se utilizar a máquina local, visto que o Google Collab pode não conseguir carregar todos os dados.
